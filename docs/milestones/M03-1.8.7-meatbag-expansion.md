## Delivered

### Correct-score betting
- Separate Correct Score sub-market inside the Casino.
- Mirrors the existing match-betting slate.
- Race-to-8 scores only.
- Fixed exact-score odds by losing score:
  - 8-0 / 0-8: 20.00
  - 8-1 / 1-8: 16.00
  - 8-2 / 2-8: 13.00
  - 8-3 / 3-8: 11.00
  - 8-4 / 4-8: 9.00
  - 8-5 / 5-8: 8.00
  - 8-6 / 6-8: 7.00
  - 8-7 / 7-8: 6.00
- Singles only.
- Cannot bet on your own match.
- Betting closes as soon as score reporting begins.
- Settlement is server-side.

### XP / Levels / Prestige
- New Progress tab.
- 25 levels per prestige.
- 500 XP per level.
- Prestige unlocks at 12,000 XP.
- Prestige resets the current XP/level bar while retaining prestige count.
- XP:
  - official pool match played: +100
  - official pool win: +200
  - positive ball difference: +10 per point
  - completed Connect 4 / Battleships: +50
  - Connect 4 / Battleships win: +100
  - completed Hog Duel: +25
  - Hog Duel win: +50
- Progression leaderboard included.

### Weekly challenges
Current fixed challenge set:
- Hat-trick: win 3 league games — 10,000 chips.
- Clock in: complete 4 league games — 5,000 chips.
- Run it up: reach +10 league ball difference — 7,500 chips.
- Rewards are claimed once per player per game week.
- Claim validation is server-side.

### Pool bounties
- New Bounties tab.
- Sponsor chooses an untouched current game-week league fixture.
- Sponsor chooses which player must win.
- 1,000–100,000 chip bounty.
- Chips escrow immediately.
- If the nominated player wins, that player receives the bounty.
- If they lose, the sponsor gets the escrow back.
- Sponsor may cancel before score reporting starts.
- Settlement is server-side.

### Fantasy
- New Fantasy tab.
- Master tiers frozen from standings before the live game week:
  - Elite: positions 1–4
  - Challengers: positions 5–8
  - Mongs: positions 9+
- Team: 1 Elite + 1 Challenger + 2 different Mongs.
- Picks lock when the first league result becomes official.
- Scoring:
  - Elite win: 10
  - Challenger win: 12
  - Mong win: 15
  - all players: 2 points per point of ball difference, including negative difference
- Weekly leaderboard.
- 50,000-chip weekly prize.
- If first place is tied, the 50,000-chip pot is split equally.
- Payout happens when the regime closes the game week.

### Battleships
- Ships may no longer touch or overlap.
- One-cell separation is enforced horizontally, vertically and diagonally.
- Manual placement, auto-placement and server validation use the same rule.
- Existing games are not rewritten; the stricter rule applies to new fleet placement.
