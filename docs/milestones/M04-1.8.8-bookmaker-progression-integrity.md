## Objective

Refine the 1.8.7 systems rather than adding another unrelated feature pile:

1. Make level and prestige visible as part of player identity.
2. Price correct-score bets from the same player-strength model as match winner odds.
3. Integrate correct score into Match Betting.
4. Rotate weekly challenges, include minigames and award XP as well as chips.
5. Close the mid-match betting exploit by requiring a server-side Start Match lock before play/result reporting.

## Delivered

### Prestige identity
- Every standard Book1 player name can now display:
  - prestige emblem
  - player name / clan tag / equipped card as before
  - current level
- Prestige emblem evolves at milestone tiers:
  - P1 bronze star
  - P2 silver shield
  - P3+ gold crown
  - P5+ red prestige crown
  - P10+ mythic gold skull
- Player identity modal also shows Prestige, Level and current-prestige XP.

### Dynamic correct-score market
- Correct Score now lives inside **Match Betting** rather than as a separate casino game.
- Uses the same record + recent-form strength model as normal match winner pricing.
- The match probability is converted into an implied per-rack probability for a race to 8.
- Exact score probabilities use the race-to-8 distribution rather than fixed score prices.
- Same configured bookmaker margin is applied.
- Correct-score price is locked when the bet is placed.
- Correct-score bets remain singles only.
- Server calculates the price; client-supplied odds are never trusted.

### Weekly challenges + XP
Three challenges are active each game week from a deterministic rotating pool.

Pool challenges:
- **Hat-trick** — win 3 league games — 10,000 chips + 750 XP
- **Clock in** — complete 4 league games — 5,000 chips + 400 XP
- **Run it up** — reach +10 league ball difference — 7,500 chips + 750 XP

Minigame challenges:
- **Four in a Row** — win 2 Connect 4 games — 5,000 chips + 500 XP
- **Naval Warfare** — win 1 Battleships game — 5,000 chips + 500 XP
- **Hog Supremacy** — win 1 Hog duel — 3,000 chips + 300 XP

Rotation:
- 2 pool challenges + 1 minigame challenge each week.
- Claim validation happens server-side.
- Claimed challenge XP feeds level/prestige progression.
- Chip rewards do not independently create XP.
- New weeks stamp a challenge start time so current-week minigame wins are attributed correctly.

### Betting integrity / Start Match
- Pool matches now have a server-authoritative Start Match lock.
- Either participant may start their own match.
- Start Match records:
  - match ID
  - start timestamp
  - player who started it
- Once started:
  - normal match betting closes
  - correct-score betting closes
  - accumulator slips cannot add the match
  - new bounties cannot be posted on it
  - existing bounty cancellation is closed
  - accumulator cash-out is disabled if an unresolved leg is now live
- A result cannot be submitted until Start Match has been pressed.
- My Book displays:
  - **Start match** before play
  - **LIVE · BETTING CLOSED** with time / starter afterwards
- Knockout and 8-man/tournament matches are also surfaced to participants for Start Match.
- Regime Results has a live betting-lock panel.
- Admin can reopen a mistaken start only if:
  - the game is still open
  - no result has been submitted
  - no player score report exists
- Player-facing checks are duplicated server-side so hiding/bypassing the UI does not reopen a market.
