## Acceptance criteria

- A player cannot confirm an overlapping or out-of-bounds Battleships fleet.
- Moving/replacing a ship cannot be blocked by its own previous cells.
- During a Battleships game each player can see which opponent ships are sunk, but never hidden ship coordinates.
- Chip purchase UI clearly reflects £1 = 50,000 chips.
- Purchase amount validation permits at least a 50,000-chip (£1) purchase.
- Existing match betting, casino, score entry, admin tools and Battleships dispatch remain unaffected.
- Any required backend/RPC change is committed as a migration before deployment.
