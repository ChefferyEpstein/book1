## Objective

Add the first reusable public-information turn-based PvP game: Connect 4 for chips.

## In scope

- Player-to-player Connect 4 challenges.
- Optional equal chip stake from both players.
- Challenger stake escrowed when challenge is created.
- Opponent stake escrowed on acceptance.
- Decline/cancel refunds the challenger.
- Random first player on acceptance.
- Server-authoritative turns and legal column drops.
- Win detection horizontally, vertically and diagonally.
- Draw detection and automatic stake refunds.
- Forfeit awards the pot to the opponent.
- Incoming challenge / your-turn navigation badge.
- Recent game history.
- Local-mode parity for development.
- Database migration v27.
- Send-ready patch notes.

## Out of scope

- Shared generic PvP database schema refactor.
- Matchmaking.
- Spectator betting on Connect 4.
- XP/challenges/prestige.
- Bounties.
- Tournament brackets.
- Chat integration.

## Acceptance criteria

- A player can challenge any other active player.
- Stakes cannot exceed the challenger's balance.
- Challenger stake is refunded if challenge is declined/cancelled.
- Opponent cannot accept without enough chips.
- Only the current player can make a move.
- A chip always falls to the lowest free row in the selected column.
- Full columns cannot accept another move.
- Four connected pieces in any legal direction ends the game.
- Winner receives the full 2x stake pot.
- A full-board draw refunds both players.
- Forfeit awards the full pot to the opponent.
- Pending and turn-required games show a nav notification.
- Cloud and local modes behave consistently.
- `book_version()` reports 27 after the migration.
