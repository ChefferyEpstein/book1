# Book1 1.9.6 — Patch Notes

## Predictions
- Correct predictions now earn **100 XP and 500 chips** each.
- The new reward applies from this update onwards; previous correct predictions are not paid retrospectively.

## Fantasy
- Added an **all-time Fantasy points leaderboard** showing the points earned by each manager's own selected team.
- Added a **previous gameweek winners** section showing recent winners and their winning scores.
- Fantasy selections now only offer players who are participating in the current gameweek.
- Selection pots and tiers continue to be based on the four-week Knockout table.

## Weekly challenges
- Refreshed the challenge mix with more variety across predictions, Bokémong battles and casino wheel spins.
- Removed the pool challenge to play six games, as everyone is expected to play six games.
- Removed the pool challenge to win six games.
- Increased Pinball game-count targets to **3 and 5 games**.
- Rebalanced Pinball score challenges around the current top score of **250,000**: 50,000, 125,000, 200,000 and 250,000.
- Casino wheel spins are now recorded in shared game data so spin challenges track reliably across devices.
- Prediction challenges count correct predictions in the current gameweek.

## Pinball
- Retains the **90-second** game and **three-ball** format.
- Pinball XP is **0.1% of score**.
- Chip rewards return **5% of the score**.
- The score multiplier now halves when a ball drains instead of resetting completely.
- Removed the old score ceiling so high scores are not rejected by an artificial cap.

## General
- Updated all in-app version labels from **1.9.5** to **1.9.6**.
- Updated the shared database version to **v52** for the latest reward and challenge logic.
